# 추론 강도 조정에 따른 답변 시간 비교 — 2026-09-13

`gpt-5.6-luna`의 추론 강도를 기본 `medium`에서 `low`로 바꿔 같은 질문을 한 번씩 실행한 결과다. 정책 실험은 라우터·답변 생성에, 세금 4건 실험은 세금 Graph의 모델 호출에 `low`를 적용했다. 숫자는 답변 완료까지의 시간이며 낮을수록 빠르다.
